Subir front em prod
Vamos usar tanto o termianl do vsCode tanto o uma janela separada.

1. Fazer build do projeto (front) (terminal vsCode);
	comando[0]: npm run build
2. logar na vpc remota (janela separada do terminal);
	comando[0]: ssh wit@wit.icmc.usp.br -p 22
3. Ir até a pasta de html e apagar todo o conteúdo da pasta front, mas n a pasta;
	comando[0]: cd var/www/html
	comando[1]: rm -r front (se apagar a pasta, basta usar o comando logo a baixo);
	comando[2]: mkdir front
4. Enviar O build atual para o servidor remoto (terminal vsCode);
	comando[0]: sftp wit@wit.icmc.usp.br
	comando[1]: put -r C:/Users/nicol/Documents/wit/site-wit-front/build/* var/www/html/front 
5. Abrir nova aba no terminal de janela separada e fazer login na vpc nesse também;
6. Ir até o diretório raiz;
	comando[0]: cd .. (até chegar em /)
7. Ir até a pasta html;
	comando[0]: cd var/www/html
8. Apagar pasta front desse dir (apagar tudo tudo mesmo, inclusive a pasta);
	comando[0]: sudo rm -r front (se n apagar a pasta é só usar o comando logo a baixo)
	comando[1]: sudo rmdir front
9. Enviar o conteúdo da pasta front que a gente subiu no passo 4 para a pasta que acessamos no passo 7;
	comando[0]: sudo cp -r front /var/www/html
10. Atualizar nginx;
	comando[0]: sudo nginx -t
	comando[1]: sudo systemctl restart nginx
11. Dar permissão para o nginx acessar a pasta front novamente.
	comando[0]: sudo chown -R www-data:www-data /var/www/html
